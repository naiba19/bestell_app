# Bestell App 🍔

A Lieferando-inspired food ordering app built with HTML, CSS and JavaScript.

## Features

- Restaurant header and hero section
- Burger, Pizza and Salad categories
- Dynamically rendered meals
- Add meals to the basket
- Increase and decrease meal quantities
- Remove meals from the basket
- Subtotal and delivery fee calculation
- Total order calculation
- Order confirmation
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` – Main page
- `style.css` – Main styling
- `styles/` – Additional CSS files
- `script.js` – Basket and application logic
- `scripts/database.js` – Meal data
- `scripts/template.js` – HTML templates
- `assets/` – Images, icons and fonts
